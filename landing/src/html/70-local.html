Runs the agents you already use. Your chats stay on your machine.

Agents
Claude Code, Codex, Kiro and Pi. Pick one per conversation, with its own model and permission mode.
Permissions
Ask before changes, Trust inside the agent’s sandbox, or YOLO where the agent supports it. Per chat or for everything.
Your chats
Stored in a SQLite database on your machine. No account needed to run locally.
Prompts
Each agent sends your prompts to its own provider.
Code
Every branch works in the same project folder. No git branches, no worktrees, no code isolation. Files change only when an agent edits them, with your permission.
Closing a pane
Never deletes history or stops a running turn. Reopen it and the turn picks up.
Remote
Optional. Point a workspace at a machine you run, over SSH. Its turns keep running there after you close the app, and that machine can serve your threads to your phone.
Platform
macOS, for now.
